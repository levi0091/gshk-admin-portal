# Issue tracker

Local markdown. Each feature lives in `.scratch/<feature>/` at the root of the checkout the conductor runs in:
`spec.md`, `issues/NN-<slug>.md`, `reviews/<kind>.md`, `scout/`, `crew-log.md`.

`.scratch/` is not committed. Personas working in their own worktree receive absolute paths to it in their brief.

Product backlog (PBIs) stays in Notion, per the workspace CLAUDE.md.
